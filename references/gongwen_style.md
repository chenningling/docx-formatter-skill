# 中文公文排版规范（GB/T 9704-2012）

适用于：党政机关公文，包括决定、通知、通报、报告、请示、批复、意见、函、纪要等。

## 页面设置

| 参数 | 值 | OpenXML（DXA） |
|---|---|---|
| 纸张 | A4（21cm × 29.7cm） | Width=11906, Height=16838 |
| 上边距 | 37 mm | 2098 |
| 下边距 | 35 mm | 1984 |
| 左边距 | 28 mm | 1588 |
| 右边距 | 26 mm | 1474 |

标准要求每行 28 个字，每页 22 行（固定行距 28pt 保证）。

## 段落样式对照表

| 样式 | 字体 | 字号 | 字号（pt） | 加粗 | 对齐 | 行距 | 缩进 |
|---|---|---|---|---|---|---|---|
| 发文标题（Title） | 方正小标宋简体 | 二号 | 22pt | ✓ | 居中 | 固定 28pt | 无 |
| 一级标题 H1 | 黑体 | 三号 | 16pt | ✗ | 左对齐 | 固定 28pt | 无 |
| 二级标题 H2 | 楷体_GB2312 | 三号 | 16pt | ✗ | 左对齐 | 固定 28pt | 2字符（32pt） |
| 三级标题 H3 | 仿宋_GB2312 | 三号 | 16pt | ✓ | 左对齐 | 固定 28pt | 2字符（32pt） |
| 正文 | 仿宋_GB2312 | 三号 | 16pt | ✗ | 两端对齐 | 固定 28pt | 2字符（32pt） |

## 字体说明

| 字体名称 | 用途 | 备注 |
|---|---|---|
| 方正小标宋简体（FZXiaoBiaoSong-B05S） | 发文标题 | 需安装方正字体，未安装时显示为系统默认字体 |
| 黑体（SimHei） | 一级标题 | Windows 内置 |
| 楷体_GB2312（KaiTi_GB2312） | 二级标题 | Windows 内置，macOS 需安装 |
| 仿宋_GB2312（FangSong_GB2312） | 正文、三级标题 | Windows 内置，macOS 需安装 |

> **macOS 用户注意**：楷体和仿宋在 macOS 上字体文件名为 `Kai` 和 `STFangsong`。
> 本技能使用 GB2312 版字体名，确保在 Windows 上打开效果正确；
> 在 macOS 上预览可能显示替代字体，但将文件发送到 Windows 环境后效果正确。

## 标题编号规范（供参考）

公文标题编号约定（本技能不自动添加）：

```
一、        ← 一级标题（黑体，不缩进）
（一）      ← 二级标题（楷体，缩进2字符）
1.          ← 三级标题（仿宋加粗，缩进2字符）
(1)         ← 正文内四级条目（仿宋，缩进2字符）
```

## 固定行距 28pt 的意义

GB/T 9704 要求固定 28pt 行距，原因：
- 确保每页恰好 22 行，便于排版计算版心
- 固定行距使公文在纸质打印时规格统一，符合档案管理要求
- OpenXML 中设置：`lineRule="exact"`, `line="560"`（DXA，28pt × 20 = 560）

## 发文标题格式说明

发文标题通常居中排布，可以多行，每行居中。若标题过长超过一行，应在语义完整处断行，禁止孤字成行。

本技能对 `Title` 样式的段落应用发文标题格式。如果用户的文档没有使用 `Title` 样式，封面标题段落将被格式化为普通正文（仿宋 16pt），需要用户手动在 Word 中将其样式改为 `Title` 后重新处理。
